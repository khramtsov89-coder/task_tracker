# task-tracker

Внутренний сервис учёта задач. REST API на Flask, хранилище — SQLite (файл `tasks.db` создаётся автоматически при первом запуске).

## Запуск

1. Ставим зависимости из `requirements.txt`
2. Запускаем `app.py`
3. Сервис поднимется на `http://127.0.0.1:5000`

## Эндпоинты

- `GET /tasks` — список всех задач
- `POST /tasks` — создать задачу, body: `{"title": "..."}`
- `GET /tasks/<id>` — получить одну задачу
- `PUT /tasks/<id>` — обновить задачу, body: `{"title": "...", "done": true/false}`
- `DELETE /tasks/<id>` — удалить задачу
